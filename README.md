# 🌸 House of Jaya – Responsive Product Landing Page

A modern, elegant, and fully responsive product landing page built using **HTML5, CSS3, and JavaScript**. This project represents a premium ethnic fashion brand and showcases responsive web design principles with a clean and professional user interface.

---

## 📖 About the Project

**House of Jaya** is a fictional ethnic fashion brand that offers premium sarees, dresses, nighties, and traditional wear.

The website is designed with a luxury aesthetic and includes all the essential sections required for a modern product landing page.

---

## ✨ Features

- Responsive Navigation Bar
- Hero Banner
- Shop by Category Section
- Featured Products
- Benefits Section
- Why Choose Us Section
- Customer Testimonials
- Call-to-Action Banner
- Professional Footer
- Smooth Scrolling
- Sticky Navigation
- Mobile Responsive Layout
- Hover Animations
- CSS Grid & Flexbox Layout

---

## 🛠️ Technologies Used
